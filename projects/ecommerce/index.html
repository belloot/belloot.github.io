Background

In my advanced Java class, our group created a simple e-commerce style website. The aim was to have user authentication, product browsing, adding to cart, and admin product management

We were encouraged to utilize AI to help us develop our work, and were free to use any programming tools/frameworks to build the website.

We ended up using Spring Boot for web development and MySQL for the database (local).

My Role

Most of my work was on the backend of our website. I worked with our team leader to configure Spring Boot’s Spring Security for registering and logging in, and figured out how to use MySQL to store our user registration data.

I also worked on the admin management page, giving us to have the ability to add and delete products. Throughout the project, I helped fix database bugs, test features, and prepare the project for class presentation.

This was one of my first class coding projects where I had to utilize third-party frameworks and software in my code (Spring Boot + MySQL) on top of the programming language. Our project was mostly from scratch (beside prior Java knowledge), so we had to collaborate, do research, and experiment. I got introduced to Spring Boot and different aspects of coding like working with databases and web development.

Learning

  • Using Java OOP
  • Using Spring Boot
  • MySQL Database (w/ MySQL Workbench)
  • Utilizing AI and asking it follow-up questions to understand concepts

Background
---

In my data structures class, we were tasked with making a console version "social media app" in Java.

We were required to use the data structures we learned about during the quarter, such as the *linked list*, *binary search tree (BST)*, *graph*, and *hash table*, to implement various required features.

Account data were to be stored inside a .txt file with specific formatting (explained in demo). Users could create **an account**, **log in**, **view their profile**, **view their friends**, **remove friends**, **search for new friends**, and **get friend recommendations**.

My Role
---

I worked very closely alongside our team lead to ensure proper logic in our code and had to understand how the data structures functioned in order to implement the required features. 

I got to touch almost every aspect of our project code. I helped read user data from the .txt file, initialize User objects with correct attributes, friends, and interests, populate the friend network, and implement the friend recommendation system. The team lead and I spent many continuous hours understanding, debugging, and improving our code.

This project demanded a lot of logical reasoning and understanding of the coding concepts from class. It was also my first group coding project. In the end, I learned a lot from this project regarding collaborative programming and felt incredibly rewarding.
